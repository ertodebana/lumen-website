Not a blazingly fast language.

Lumen is a small, dynamically typed language with closures, first-class functions and errors that name the line. It computes fib(30) in 0.64 seconds. Python does it in 0.08.

Lumen walks the syntax tree on every call and looks each variable up in a hash map. That is the simplest way to build an interpreter and the slowest way to run one. Here it is about eight times slower than Python, and about a hundred and sixty times slower than the Rust it is written in.

Intel Core i7-13700H, Linux. One benchmark, one machine: treat it as an anecdote.

What you get instead

  • A language that fits in your head. Thirteen keywords and two built-in functions. The whole syntax is one page of the handbook.
  • Functions that remember. Closures and first-class functions are the only way to build anything larger, so they work properly.
  • Errors that name the line. Every failure says what went wrong and where, then stops.
  • A prompt that keeps your work. Multi-line blocks, history, and results echoed back as you type.

Try it

Lumen builds to one native executable. You need a Rust toolchain; nothing else.
